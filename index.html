Phish Guard

Lexical URL Analysis, Random Forest Classifier & Multi-Stage Development

A phishing-detection project combining lexical URL analysis, machine learning, and browser-extension functionality, with later development exploring external safety checks and LLM-assisted analysis.

✎ Distinct development phases · Original ML prototype & later cloud/LLM exploration
KEY ENGINEERING HIGHLIGHTS & DEVELOPMENT PHASES:
  • Original ML Prototype: Engineered URL feature extraction in Python with 10 structural indicators—including Shannon entropy ($-\sum p \log_2 p$) for character randomness, IPv4-based host heuristics, and token length—trained on a Scikit-Learn Random Forest model.
  • Browser Extension: Built a client-side browser extension interface to inspect active URLs and surface local heuristic risk flags directly to the user.
  • Later Development Exploration: Created a secondary Node.js service exploring external threat verification via the Google Safe Browsing API and semantic intent inspection via the Gemini API (distinct exploratory phase).

About

I am driven by the intersection of rigorous systems programming and purposeful interface design. Whether formulating a dynamic programming matrix to resolve messy user queries in real time, or computing mathematical Haversine spherical distances to enforce physical campus attendance without intrusive hardware, I treat software engineering as an exact discipline.

During my academic journey at Christ University and competitive hackathons, I have developed a strong bias toward verified code quality: writing isolated unit tests, defining strict API schemas, and structuring maintainable architectures. I avoid black-box shortcuts when a mathematically transparent algorithm can solve the problem with predictable complexity.
