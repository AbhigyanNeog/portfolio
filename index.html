Smart Faculty Attendance System

VeriClass: Haversine GPS Geofencing, Live Photo Capture & Timetable OCR Parser

An automated institutional presence-verification system engineered with Python and Flask. VeriClass mitigates classroom proxy attendance by calculating spherical Haversine distances against campus coordinates, capturing real-time classroom photos with OpenCV/Pillow JPEG compression, and parsing complex multi-format timetable documents into verified schedule slots.

✎ Haversine distance threshold ≤ 50m geofence

  • Resilient SQLAlchemy Data Layer: Designed dual-mode database support for local SQLite (with Write-Ahead Logging & Foreign Keys) and production PostgreSQL on Render, verified by automated test suites.

PROJECT 03 / 06 CLASSICAL ALGORITHMS & NLP COPILOT
2026 ● COMPLETE HACKATHON SYSTEM (TEAM OF 5)

Campus Copilot

Algorithmic University Assistant Powered by 4 Classical DSA Implementations

Built during a 5-hour hackathon, Campus Copilot is an intelligent university assistant combining Pandas analytics, Matplotlib charts, and Folium geospatial mapping. Rather than relying on opaque deep-learning models, it showcases four classical algorithms directly mapped to concrete student features: Levenshtein Distance, Activity Selection, 0/1 Knapsack, and Binary Search.

🏆 Top 5 Finalist · Samsung Campus Hackathon
VERIFIED INDIVIDUAL CONTRIBUTION: Core Algorithm & NLP Engineer — Implemented the 4 classical DSA algorithms in src/algorithms.py and the tokenized fuzzy-matching intent engine in src/chatbot.py.
KEY ENGINEERING HIGHLIGHTS:
  • 4 Classical DSA Algorithmic Models: Dynamic Programming Levenshtein Distance for typo-tolerant NLP ("evnts" → "events"); Greedy Activity Selection for conflict-free event scheduling; 0/1 Knapsack for sponsorship budget optimization; Binary Search for date retrieval.
  • Fuzzy Intent Dispatcher: Built an intent router utilizing O(1) hash table lookups with Levenshtein matrix fallback and priority tie-breaking.
  • Geospatial & Visual Analytics: Generated interactive campus maps via Folium/Leaflet and dynamic financial distribution charts with Pandas and Matplotlib.

PROJECT 05 / 06 DUAL-ENGINE PHISHING & THREAT DEFENSE
2025 – 2026 ● COMPLETE DUAL-PHASE PLATFORM

Phish Guard

10-Feature Shannon Entropy ML Classifier & Hybrid Cloud Threat Intelligence

A dual-engine cybersecurity solution that protects users against malicious URLs. Phase 1 features an engineered Scikit-Learn Random Forest model extracting 10 lexical indicators—notably calculating Shannon Informational Entropy to detect character obfuscation—delivered via a Manifest V3 Chrome Extension. Phase 2 extends detection with Node.js, Google Safe Browsing API v4, and Gemini 2.5 Flash.

⚑ Shannon entropy math + Random Forest classifier
KEY ENGINEERING HIGHLIGHTS:
  • Shannon Entropy Mathematical Feature: Engineered shannon_entropy calculating informational randomness ($-\sum p \log_2 p$) to expose algorithmic obfuscation and domain impersonation.
  • 10-Feature Random Forest Classifier: Extracted structural metrics (URL length, IPv4 host detection, hyphen/digit density, HTTPS protocol) trained and serialized via Joblib.
  • Multi-Tier Cloud Protection: Architected a secondary Node.js defense pipeline fusing Google Safe Browsing threat lookups with Gemini LLM semantic intent analysis.

I am driven by the intersection of rigorous systems programming and purposeful interface design. Whether formulating a dynamic programming matrix to resolve messy user queries in real time, or computing mathematical Haversine spherical distances to enforce physical campus attendance without intrusive hardware, I treat software engineering as an exact discipline.

During my academic journey at Christ University and competitive hackathons, I have developed a strong bias toward verified code quality: writing isolated unit tests, defining strict API schemas, and structuring maintainable architectures. I avoid black-box shortcuts when a mathematically transparent algorithm can solve the problem with predictable complexity.
